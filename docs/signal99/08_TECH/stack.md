# Technical Stack

Recommended:
- Next.js App Router
- TypeScript strict
- Tailwind CSS
- Stripe Checkout
- Supabase if needed
- Zod for validation
- next/image
- dynamic OpenGraph
- PWA support

## MVP Routes
- `/`
- `/test`
- `/result/[id]`
- `/success`
- `/cancel`
- `/share/[slug]`
- `/legal`
- `/privacy`
- `/terms`
