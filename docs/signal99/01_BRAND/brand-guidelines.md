**SIGNAL99**

## Positionnement
SIGNAL99 est une expérience d’identité personnelle symbolique, premium et partageable.

Ne jamais présenter comme :
- app IA visible ;
- horoscope ;
- voyance ;
- diagnostic psychologique ;
- prédiction ;
- outil scientifique.

Présenter comme :
- expérience symbolique ;
- identité personnelle ;
- carte unique ;
- présence invisible ;
- archétype social ;
- produit premium et partageable.
